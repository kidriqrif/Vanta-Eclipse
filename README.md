# Vanta Eclipse

An idle RPG for Android (Google Play), with Steam and iOS planned later.
C#, portrait, offline, no paywall.

Pixel art on a closed sixteen-colour palette — and **every asset is generated**:
the sprites, the bitmap font, the icons and all the sound come out of programs
in [`tools/`](tools/), not out of an editor. A palette change is one edit and
one command. The validation sweep fails on any pixel outside the sixteen, on
any font size that is not a whole multiple of the glyph box, and on any asset
that no longer matches the program that draws it.

## Getting started

1. Install [Unity 6000.5.7f1](https://unity.com/releases/editor/archive) with
   **Android Build Support** (including the OpenJDK and Android SDK/NDK modules).
2. Clone this repository.
3. Open Unity Hub, click **Add**, and select the repository root.
4. Open `Assets/Scenes/MainMenu.unity` and press **Play**.

The managers boot from a `[RuntimeInitializeOnLoadMethod]` before the first
scene loads, so entering play mode on any screen works — you do not have to
start from the main menu.

The first time you open the project, Unity creates `Library/`, `Temp/` and
`Logs/`. None of them are committed (see `.gitignore`).

## Project structure

| Folder | Contents |
| --- | --- |
| `Assets/Scenes/` | One `.unity` scene per screen |
| `Assets/Resources/Prefabs/` | The components screens spawn: banners, toasts, modals, the arcade boards |
| `Assets/Scripts/Core/` | The service locator, the event bus, the runtime driver, and the save layer |
| `Assets/Scripts/Managers/` | The game systems — see the boot-order table in `docs/ARCHITECTURE.md` |
| `Assets/Scripts/Data/` | `ScriptableObject` subclasses defining the shape of every content asset |
| `Assets/Scripts/UI/` | One behaviour per screen, plus the shared widgets and the theme |
| `Assets/Resources/Content/` | All game content as `.asset`: enemies, upgrades, affixes, relics, pets, skills, quests, worlds, minigames, products |
| `Assets/Resources/Art/`, `Assets/Resources/Audio/`, `Assets/Resources/Fonts/` | Game assets. All **generated**: `tools/make_sprites.py`, `make_audio.py` and `make_font.py` are the source, the files are build output |
| `Assets/Resources/Shaders/` | `PixelRim.shader`: a hard one-texel outline. Pixel art carries its own shading, so the shader adds only the silhouette |
| `Assets/Editor/` | The build pipeline, the asset importers, and the smoke test |
| `tools/` | The validation sweep (`validate_all.sh`) and its checkers |
| `docs/`, `design/` | Architecture documentation and the UX/GDD specs |

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for how the systems fit together.

## Where is my save file?

Progress is written to Unity's persistent data folder:

* Windows: `%USERPROFILE%\AppData\LocalLow\Vantrexa Games\Vanta Eclipse\`
* Linux: `~/.config/unity3d/Vantrexa Games/Vanta Eclipse/`
* Android: internal app storage

Files: `savegame.json` (progress) and `savegame.backup.json` (automatic
backup). Volumes and preferences are separate, in `PlayerPrefs` — losing a
save must never also reset the audio to full.
